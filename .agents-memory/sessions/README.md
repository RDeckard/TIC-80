# Sessions

This directory stores session summaries (cold context).

## Rules
- One file per meaningful session.
- Recommended filename format: `YYYY-MM-DD-note.md`.
- Minimum content:
  - Context
  - Actions performed
  - Decisions made
  - Next steps
- Keep entries concise and in English.
- Do not auto-load this directory; use `../indexes/cold-manifest.md`.
